# Запуск проекта AI CCTV Retail Security — пошаговый план

## 🔍 Что это за проект (простым языком)

Это система **видеонаблюдения с искусственным интеллектом**, которая:
- Анализирует видео с камер наблюдения в магазине
- **Автоматически обнаруживает кражи** (shoplifting) в реальном времени
- Показывает результат в удобном веб-интерфейсе (дашборде)

**Как это работает:**
1. Вы загружаете видео с камеры наблюдения
2. ИИ-модель **VideoMAE** смотрит по 16 кадров за раз и анализирует **движения** людей (как руки двигаются к карманам, как прячут товар)
3. Вторая модель **YOLOv8** рисует прямоугольники вокруг людей на видео
4. Система выдаёт оповещение, если обнаружена подозрительная активность

> [!NOTE]
> **Точность модели** — 97.4% распознавания краж, всего 0.9% ложных срабатываний. Это очень высокая точность для подобных систем.

### Шаг 1: Создать виртуальное окружение (venv)

**Что это?** Виртуальное окружение — это изолированная копия Python для этого проекта. Все библиотеки устанавливаются только в неё и не мешают другим проектам.

```bash
cd "c:\Users\NOOLFJ\Desktop\Python detector PROJECT\AI-CCTV-Retail-Security-main"
python -m venv venv
venv\Scripts\activate
```

---

### Шаг 2: Установить PyTorch с поддержкой GPU

**Что это?** PyTorch — основной фреймворк для ИИ. Нужна специальная версия для вашей видеокарты RTX 3060 Ti.


> [!NOTE]
> Это скачает ~2.5 ГБ. Нужен стабильный интернет.

## 📚 Ключевые понятия (что нужно знать)

### Термины ИИ, встречающиеся в проекте

| Термин | Простое объяснение |
|--------|-------------------|
| **Модель (Model)** | Обученная программа, которая "научилась" отличать кражу от нормального поведения на видео |
| **Веса модели (Weights)** | Файлы с "знаниями" модели — результат обучения на тысячах видео. Без них модель ничего не умеет |
| **VideoMAE** | Конкретная архитектура ИИ, которая анализирует видео (16 кадров за раз), а не отдельные картинки |
| **YOLOv8** | Быстрая модель для обнаружения объектов — здесь ищет людей на кадре и рисует рамки |
| **Threshold (Порог)** | Число от 0 до 1. Если модель "уверена" больше порога — кричит "КРАЖА!". Порог 0.80 = модель должна быть уверена на 80%+ |
| **Inference (Инференс)** | Процесс применения обученной модели к новым данным (в отличие от Training — обучения) |
| **CUDA** | Технология NVIDIA, позволяющая использовать видеокарту для вычислений ИИ. Без неё всё работает на CPU (в 10-20 раз медленнее) |
| **Fine-tuning** | Дообучение: берём готовую модель и дообучаем на конкретных данных (видео краж) |
| **F1 Score** | Метрика качества, баланс между "нашёл все кражи" и "не кричал ложно". 98.1% — отлично |
| **Streamlit** | Фреймворк для быстрого создания веб-интерфейсов из Python-кода |
| **venv** | Виртуальное окружение — изолированная "песочница" для библиотек Python |

### Что НЕ делает эта система
- ❌ Не распознаёт лица (нет идентификации личности)
- ❌ Не следит между камерами (работает с одной камерой)
- ❌ Не работает в реальном времени без GPU
